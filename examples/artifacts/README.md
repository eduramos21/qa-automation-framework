# examples/artifacts

Real output from the agents, committed so you can see what each workflow
produces without having to run it first.

Filled in as the phases land:

| From | Lands in |
|---|---|
| A refined requirement, `/qa:refine` | phase 2 |
| A test design with a coverage matrix, `/qa:design` | phase 2 |
| A generated test, next to the design that produced it, `/qa:generate` | phase 3 |
| An exploratory session sheet, `/qa:explore` | phase 4 |
| A suite audit report, `/qa:audit` | phase 5 |
